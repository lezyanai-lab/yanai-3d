# Yanai 3D Models

קטלוג הדפסות תלת-ממד (עברית, RTL). React + Vite + Tailwind, מתארח ב-GitHub Pages.
האתר הוא PWA: אפשר להתקין אותו כאפליקציה בטלפון, והוא נפתח גם בלי אינטרנט (אחרי ביקור ראשון).

## ניהול האתר

כל התוכן נערך ממסך המנהל באתר: תפריט ← הגדרות, כניסה עם אימייל וסיסמה.
מוצרים, צבעים ומלאי, שאלות נפוצות, הגדרות האתר (כולל מצב תחזוקה) וגיבוי.
כל שמירה נרשמת ב-GitHub, והאתר מתעדכן תוך כדקה-שתיים.

הנתונים נשמרים בתיקייה `content/`, בנפרד מהקוד. בעדכון קוד מעלים רק את `src/`, ואין לגעת ב-`content/` ידנית, כי זה דורס את מה שנשמר ממסך המנהל:

- `content/products.json` — מוצרים
- `content/colors.json` — צבעים ומלאי
- `content/faq.json` — שאלות נפוצות
- `content/settings.json` — הגדרות האתר
- `content/admin.json` — כניסת המנהל (מוצפן). נוצר בעזרת `node make-admin.mjs`

## הרצה מקומית

1. Node.js 18 ומעלה.
2. `npm install`
3. `npm run dev`

אופציונלי: אייקון האפליקציה מהלוגו — `npm install --no-save sharp` ואז `node make-icons.mjs`
(דורש `public/images/logo.jpg`).

## פרסום

Settings ← Pages ← Source: **GitHub Actions**. כל שמירה ל-`main` בונה ומפרסם את האתר.

## התקנה בטלפון

- **אנדרואיד (Chrome):** כפתור "התקן את האפליקציה" באתר, או תפריט ⋮ ← "התקן אפליקציה".
- **אייפון (Safari בלבד):** שיתוף ← "הוסף למסך הבית".

## מבנה

- `src/` — קוד האתר
- `content/` — הנתונים שנערכים ממסך המנהל (ראה למעלה)
- `public/images/` — תמונות (מוצרים, לוגו, Bit)
- `public/sw.js` — שמירת האתר לעבודה בלי אינטרנט. אחרי שינוי גדול כדאי להגדיל את `CACHE` (למשל `yanai3d-v2`)
